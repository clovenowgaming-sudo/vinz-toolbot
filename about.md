# Vinz Tool Bot

Macro bot untuk Geometry Dash 2.2081.

- Tombol **REC** dan **PLAY** di pause menu (kiri)
- Tombol **+** di bawah teks `input:` untuk mengatur TPS
- Tombol **Macro** untuk save / load / export / import
- Format macro: **GDR2** (GDReplayFormat)
- Practice fix, dan death di practice mode tidak ikut terekam
